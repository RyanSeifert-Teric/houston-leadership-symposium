# Houston Leadership Symposium Mockup

Static mockup for Houston Leadership Symposium.

## Pages

- `index.html` - homepage mockup
- `profiles.html` - membership profile mockup

## Local Preview

```powershell
python -m http.server 8097 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8097/`.

This is intentionally static HTML/CSS/assets so it can deploy directly on Vercel with no build step.
